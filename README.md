# 📝 Online Meeting Summarizer

An intelligent Chrome Extension that transcribes online meeting audio in real time, generates concise summaries, and translates them into multiple languages — so you never miss key points again.

## 🚀 Features

### 🎙 Real-time Audio Transcription
- Captures and converts meeting audio into text as the meeting happens.

### 🧠 AI-Powered Summarization
- Automatically generates clear and concise summaries of long discussions.

### 🌍 Multi-Language Translation
- Translates summaries into different languages for global accessibility.

### 🧩 Chrome Extension
- Lightweight, easy-to-use, and works directly in your browser during online meetings.

### ⏱ Time-Saving & Productivity Boost
- Focus on the conversation — let the extension handle notes.

### 💾 Easy saving and sharing
- Downloadable summaries (PDF / DOC)

## 🛠️ Tech Stack

- Speech-to-Text Engine (speech_recognition)
- NLP Model for summarization (Python)
- Translation (googletrans)
- Chrome Extension (JavaScript, HTML, CSS)

## 🧪 How It Works

- Join an online meeting (Google Meet, Zoom Web, etc.).
- Start the extension to begin audio transcription.
- Speech is converted to text in real time.
- The transcript is processed to generate a summary.
- The summary can be translated into the selected language.
- View and save the final output instantly.
